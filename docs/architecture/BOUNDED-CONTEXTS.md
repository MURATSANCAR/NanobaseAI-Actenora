## Package convention

```text
com.nanobaseai.actenora.<context>.{api,domain,application,infrastructure}
com.nanobaseai.actenora.sharedkernel
```

- Public surface: `<context>.api` (`@NamedInterface("api")`)
- Internal: `domain`, `application`, `infrastructure` — blocked by Modulith + ArchUnit

## Relationship styles

| From → To | Style |
|-----------|-------|
| * → audit | Integration events / outbox only |
| approval → delivery | Explicit grant via `approval :: api` |
| meeting → transcript | Opaque `MeetingId` + events (never `MeetingEntity`) |
| aiprocessing → meetingintelligence | **Forbidden** table/entity access |
| delivery → approval.domain | **Forbidden** entity imports |
